# Personas for Academic Cloud

A collection of personas, that is LLMs with specific instructions and data for retrieval augmented generation (RAG), to be used with https://academiccloud.de/de/services/chatai/.

See https://github.com/gwdg/chat-ai-personas for more information and https://chat-ai.academiccloud.de/arcanas/ to upload data for RAG, which is stored in so called arcanas.

## Personas

### eds_tutor

Answers student questions for the course 'Introduction to Digital Signal Processing' and is based on https://github.com/gwdg/chat-ai-personas/blob/main/arcanas/fegis-bot.json. EDS tutor is available from

```
https://chat-ai.academiccloud.de/chat?import=https://raw.githubusercontent.com/f-brinkmann/academiccloud_personas/refs/heads/main/eds_tutor.json
```
